# 🌾 AgroPreciosVE

Estimador de precios de rubros agrícolas en los principales mercados
mayoristas de Venezuela.

> ⚠️ **Aviso importante:** Los precios que muestra esta app son
> **estimados de referencia** y **NO son precios oficiales**.
> Deben actualizarse manualmente consultando los mercados.

## 🎯 Objetivo

Ofrecer una herramienta ligera que permita consultar el precio estimado
al mayor de rubros agrícolas en:

- Mercado de Coche (Caracas)
- Mercabar (Barquisimeto)
- Mercamara (Maracaibo)

## 🛠️ Tecnologías

- **Backend:** Node.js + Express
- **Frontend:** HTML5, CSS3, JavaScript vanilla
- **Datos:** archivo JSON local (`data/precios.json`)
